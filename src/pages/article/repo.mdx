R.E.P.O. is a co-op horror game where players (semibots) are tasked with carrying valuable objects using [Gmod](/article/gmod)-like physics to extraction points in various haunted locations and return to the van in one piece. It uses peer-to-peer online multiplayer and proximity voice chat, features a random cosmetic drop system, and is moddable using [BepinEx](https://github.com/BepInEx/BepInEx).

## Cosmetic Crate Chances

Each level, there are a set number of cosmetic crates with a specific chance to spawn. If spawned, their rarity (Common, Uncommon, Rare and Ultra Rare) is also determined by a set of probabilities. All chances are documented in [this spreadsheet](https://docs.google.com/spreadsheets/d/1e1RWktrA_HIHIb-SlKdSI672JUhYcJmh/edit?usp=sharing).

## Favourite Mods

All mods can be found on the unofficial [Thunderstore page](https://thunderstore.io/c/repo).

The below mods are hard requirements that are used by some of the subsequent mods, and should be installed regardless:

- [MenuLib](https://thunderstore.io/c/repo/p/nickklmao/MenuLib/)
- [REPOConfig](https://thunderstore.io/c/repo/p/nickklmao/REPOConfig/)
- [REPOLib](https://thunderstore.io/c/repo/p/Zehs/REPOLib/)

For standard gameplay, the following mods are recommended:

- [CosmeticBoxConfig](https://thunderstore.io/c/repo/p/khalil/CosmeticBoxConfig/)
- [FNAFLevel](https://thunderstore.io/c/repo/p/OrtonLongGaming/FNAFLevel/)
- [FreddyEnemy](https://thunderstore.io/c/repo/p/OrtonLongGaming/FreddyEnemy/)
- [REPOGambling](https://thunderstore.io/c/repo/p/DirtyGames/REPOGambling/)
- [ShopBlacklist](https://thunderstore.io/c/repo/p/Aolion/ShopBlacklist/)
- [SkyLevelCooldown Skydorm](https://thunderstore.io/c/repo/p/Skydorm/SkyLevelCooldown_Skydorm/)
- [SillyValuables](https://thunderstore.io/c/repo/p/Sangrento/SillyValuables/)
- [TheFacility](https://thunderstore.io/c/repo/p/grey5525/TheFacility/)
- [Wesleys Enemies](https://thunderstore.io/c/repo/p/Magic_Wesley/Wesleys_Enemies/)
- [Wesleys Levels](https://thunderstore.io/c/repo/p/Magic_Wesley/Wesleys_Levels/)
- [WitherholdKeep](https://thunderstore.io/c/repo/p/DirtyGames/WitherholdKeep/)

Alternatively, if playing R.E.P.O. as part of an [Archipelago](/article/archipelago) run, install the [Archipelago Randomizer for REPO](https://thunderstore.io/c/repo/p/Automagic/Archipelago_Randomizer_for_REPO/) mod. Mods that add new content are not compatible with this mod.
